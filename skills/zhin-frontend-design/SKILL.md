# Frontend design

Clarify the audience, primary task and existing framework. Inspect existing components and reuse their design tokens. Propose a coherent layout before editing. Implement semantic HTML, keyboard navigation, visible focus and responsive layouts. Include loading, empty and error states for asynchronous content. Test at narrow and wide widths. Report files changed and any verification gaps. Do not introduce dependencies without checking the project conventions.
