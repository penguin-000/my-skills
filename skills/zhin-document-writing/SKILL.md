# Document writing

Determine the audience, purpose and expected output format. Read the provided sources, separate facts from assumptions, and create a brief outline. Lead with the main conclusion or required action. Use clear headings, short paragraphs and concrete language. Retain traceable references for factual claims. Mark missing information rather than fabricating it. For binary document formats, first check the available document tools; do not claim a file was created unless it exists. Review terminology and consistency before delivery.
