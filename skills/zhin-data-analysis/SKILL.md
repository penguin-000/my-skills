# Data analysis

Identify the business question, data source, units, time range and metric definitions. Inspect schema, missing values, duplicates and outliers before computing results. Use available local analysis tools; do not assume Python packages exist. Preserve source files and write derived results separately. Explain denominators, aggregation and exclusions. Distinguish observations from causal claims. Give concise findings with supporting numbers and state limitations. Never invent missing data.
